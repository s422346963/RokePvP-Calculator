# Update Spirit Stats

该技能用于调整 `data/spirits.js` 文件中精灵的资质数据。

## 使用方法

当用户要求修改某个精灵的资质数据时调用此技能。

用户需要提供以下信息：

- **n**: 精灵名称
- **hp**: 生命（可选）
- **pa**: 物攻（可选）
- **ma**: 魔攻（可选）
- **pd**: 物防（可选）
- **md**: 魔防（可选）



## 功能说明

1. 读取 `data/spirits.js` 文件
2. 根据精灵名称查找对应的精灵数据
3. 更新指定的资质属性
4. 保存修改后的文件

    
## 示例

```
请帮我修改龙鱼的资质：生命:90->77 魔攻:34-20，那么将龙鱼的hp改为77，ma改为20
```
