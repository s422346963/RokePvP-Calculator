# Add Spirit Skill

该技能用于新增一只精灵的数据。

## 使用方法

当用户要求添加新精灵时调用此技能。

用户需要提供以下信息：
- **n**: 精灵名称
- **hp**: 生命
- **pa**: 物攻
- **ma**: 魔攻
- **pd**: 物防
- **md**: 魔防
- **sp**: 速度
- **tr**: 特性名称
- **trait_desc**: 特性描述（如果是新特性）

## 功能说明
1. 在 `data/spirits.js` 中添加新精灵数据，a1、a2、st、img 留空
2. 在 `data/spirit_trait.js` 中添加新特性描述（如果特性不存在）
3. 在 `data/spirit_skill.js` 中添加空技能数组

## 说明

spirits.js数据结构：

```
  [
      {
        "n": "遁地鼠（储水期的样子）",
        "hp": 112,
        "pa": 118,
        "ma": 23,
        "pd": 85,
        "md": 131,
        "sp": 100,
        "a1": "地",
        "a2": "",
        "st": "最终形态",
        "tr": "警惕",
        "img": ""
      }
  ]
```

spirit_trait.js数据结构：

```
{
		'警惕': '使用技能时，敌方获得2层中毒。',
  		'鼓气': '使用能耗为3的技能时，获得攻防+20%。',
}
```

spirit_skill.js数据结构

```
{
  不咕钟: [],
  九尾狐: [],
}
```



## 示例：

​	新增精灵：学院呱呱

​	生命 132
​	物攻 99
​	魔攻 99
​	物防 92
​	魔防 92
​	速度 100
​	特性
​	留学生
​	自己全技能能耗+2,可以学习全部攻击技能。
​	

	在data/spirits.js中新增数据
	{
	    "n": "学院呱呱",
		"hp": 132,
		"pa": 99,
		"ma": 99,
		"pd": 92,
		"md": 92,
		"sp": 100,
		"a1": "",
		"a2": "",
		"st": "",
		"tr": "留学生",
		"img": ""
	}
	在data/spirit_trait.js中新增一条特性描述
	'留学生': '自己全技能能耗+2,可以学习全部攻击技能'
	
	在data/spirit_skill中添加学院呱呱的技能数据
	{
	    其他精灵:[]
	    学院呱呱: []
	}
