# 洛克王国 PVP 伤害计算器

> 一个用于计算洛克王国 PVP 对战中伤害的工具，帮助玩家更好地制定战斗策略。

## 📖 简介

本项目是一个纯前端网页工具，支持洛克王国中精灵的 PVP 伤害计算。通过输入攻击方和防御方的精灵信息、技能、性格、等级等参数，精确计算出战斗中的伤害值。

**代码来源**：[lovepvp.top](https://lovepvp.top/)
**数据来源**：[BWiki 精灵图鉴](https://wiki.biligame.com/roco/)

## ✨ 功能特性

- 🎯 **精灵选择**：支持搜索和选择攻击方/防御方精灵
- 📊 **属性计算**：自动计算性格对属性的修正（生命、物攻、魔攻、物防、魔防、速度）
- ⚔️ **技能系统**：支持技能选择，包含技能威力、属性、效果等
- 🛡️ **特性系统**：支持精灵特性查询和应用
- 🔢 **伤害计算**：精确计算 PVP 对战中的伤害范围
- 🌙 **深色模式**：支持夜间模式切换
- 📱 **响应式设计**：适配不同屏幕尺寸

## 🎮 使用方法

1. 打开 `index.html` 文件（可直接在浏览器中打开）
2. 选择**攻击方精灵**：
   - 在搜索框中输入精灵名称
   - 选择精灵后查看其属性
   - 设置性格、等级、努力值等参数
   - 选择使用的技能
3. 选择**防御方精灵**：
   - 同样搜索并选择防御方精灵
   - 设置防御方的性格、等级、努力值等
4. 点击计算按钮，查看伤害计算结果
