# 洛克王国 PVP 伤害计算器

> 一个用于计算洛克王国 PVP 对战中伤害的工具，帮助玩家更好地制定战斗策略。

## 📖 简介

本项目是一个纯前端网页工具，支持洛克王国中精灵的 PVP 伤害计算。通过输入攻击方和防御方的精灵信息、技能、性格、个体值、能力等级等参数，精确计算出战斗中的伤害值。

**代码来源**：[lovepvp.top](https://lovepvp.top/)
**数据来源**：[BWiki 精灵图鉴](https://wiki.biligame.com/nrc/%E7%B2%BE%E7%81%B5%E5%9B%BE%E9%89%B4)

## ✨ 功能特性

- 🎯 **精灵选择**：600+ 只精灵（含不同形态/首领），支持名称 / 全拼 / 首字母搜索，下拉列表按属性分组、可折叠浏览
- 📊 **属性计算**：性格修正、个体值（0/60 点击切换）、能力等级实时折算六项实战属性；点击属性格可切换物攻/魔攻、物防/魔防参与计算
- ⚔️ **三种计算模式**：
  - **单技能快捷**：直接输入游戏内显示的威力（已含特性/克制/能级等全部加成），适合快速验伤
  - **单技能参数配置**：从技能库选技能自动带出类型/属性，克制、本系、能力等级倍率自动填入，也可手动调整
  - **完整技能配置**：攻防双方各配置 4 个技能，左右面板对比伤害，点击技能查看明细
- 🛡️ **特性系统**：攻防特性自动判定并计算倍率；条件类特性（先手、叠加次数、印记层数等）动态生成输入框；威力加法型特性（如蒸汽膨胀）提供「特性威力」输入
- 🔢 **变动威力技能**：闪击/鸣沙陷阱（按速度差/物防差查表）、魔能爆（按剩余能量查表）、愿力冲击（取物攻/魔攻较高者，应对状态技能时威力×2.5）自动换算威力
- ⭐ **星陨印记**：输入印记层数自动追加星陨伤害（威力 x²+24x−24，幻系技能不触发）
- ✨ **额外倍率与减伤**：支持「防御方应对技能减伤 %」与「其他额外倍率」（内置 x1.0~x4.0 快捷按钮）
- 💾 **收藏夹**：攻防配置一键保存/加载（含性格、个体值、技能），可拖动的浮动面板，位置与开关状态持久化
- 🌙 **主题切换**：日间/夜间主题，偏好本地保存
- 📱 **响应式设计**：适配桌面与移动端

## 🎮 使用方法

1. 打开 `index.html` 文件（可直接在浏览器中打开，或用 `python -m http.server 8080` 起本地服务）
2. 选择**攻击方精灵**：
   - 在搜索框中输入名称/拼音/首字母（下拉列表按属性分组）
   - 设置性格、个体值、能力等级等参数
3. 选择**防御方精灵**：同上
4. 在「⚡ 技能参数」中选择模式并填写参数：
   - **单技能快捷计算**：输入游戏内显示的技能威力、连击次数，选择物/魔类型
   - **单技能参数配置**：从技能库选择技能，按需修正各项倍率
   - **完整技能配置**：为攻防双方各配置 4 个技能，点击技能查看左右对比明细
5. 按需填写星陨印记层数、防御方减伤、其他额外倍率
6. 结果随参数自动实时更新，无需手动点击计算；右上角 ⭐ 可打开收藏夹保存/加载配置

## 📁 项目结构

```
RokePvP-Calculator/
├── index.html          # 主页面：约 520 行纯 HTML + 末尾的脚本引用（无行内脚本）
├── css/
│   └── head.css        # 唯一样式表（主题变量、卡片、布局）
├── js/                 # 计算与交互逻辑（经典脚本，按序加载，共享全局作用域）
│   ├── 01-core.js      #   搜索匹配 / 愿力冲击注入 / state / 面板值 / 性格 / 克制 / 查表
│   ├── 02-damage.js    #   伤害公式（computeDamage 唯一实现点）/ 四层拆解渲染
│   ├── 03-trait.js     #   特性倍率计算与特性面板（显隐 / 条件框 / 输入读写）
│   ├── 04-power.js     #   技能威力条件渲染 / 变动威力解析 / 威力提示
│   ├── 05-card.js      #   精灵卡片 / 搜索下拉 / 能力等级 / IV / 数值下拉
│   ├── 06-calc-ab.js   #   模式 A/B：switchMode / calc / 技能下拉
│   ├── 07-full.js      #   FULL 模式：双方 4 技能配置与对比计算
│   └── 08-fav-init.js  #   收藏夹 / 主题 / 弹窗 / 事件绑定 / 初始化入口
├── data/               # 游戏数据（全局常量，在 js/ 之前按序加载）
│   ├── spirits.js      # 精灵数据：编号/名称/六项种族值/属性/特性/形态/图片
│   ├── skills.js       # 技能数据：名称/属性/威力/类型/能耗/描述
│   ├── type.js         # 属性克制数据
│   ├── traitMult.js    # 攻/防特殊特性规则表（条件输入与倍率计算）
│   ├── skillMult.js    # 技能威力修正规则表
│   ├── pinyin.js       # 拼音搜索映射
│   └── spiritsPvP.js   # PvP 专用精灵数据
├── gen_pinyin.py       # 拼音映射生成脚本（从精灵/技能名生成 data/pinyin.js）
├── design.md           # 视觉与交互设计规范
├── AGENTS.md           # AI 协作与数据更新约定
├── analytics.js        # 访问统计（百度统计）
└── .codebuddy/         # AI 数据同步技能（用法见 AGENTS.md）
    └── skills/
        ├── sync-spirits/   # 按编号范围批量从 wiki 同步精灵
        ├── sync-skills/    # 从 wiki 技能图鉴批量同步技能
        ├── add-spirit/     # 新增精灵
        └── update-spirit/  # 更新精灵资质
```

> ⚠️ `data/` 与 `js/` 均为经典脚本（禁 `type="module"`、禁 `defer`），加载顺序即依赖顺序，调整前请读 [`AGENTS.md`](./AGENTS.md) 的架构约束。

## 🛠️ 开发约定

- 无构建系统、无依赖、无 package.json：改完直接刷新页面即可验证
- 计算逻辑按层分布在 `js/01-core.js` ~ `js/08-fav-init.js`（职责见上方结构）；改逻辑去对应的 `js/*.js`，改数据去 `data/*.js`
- 改 UI 前先读 [`design.md`](./design.md)；AI 协作、脚本加载约束与回归验证方法见 [`AGENTS.md`](./AGENTS.md)
- 精灵/技能数据请通过 `.codebuddy/skills/` 下的 AI 技能从 BWiki 同步，不要凭记忆手写数值
- 新增或修改精灵/技能名后，运行 `python gen_pinyin.py` 重新生成 `data/pinyin.js`（需 `pip install pypinyin`，脚本会自动备份原文件）
