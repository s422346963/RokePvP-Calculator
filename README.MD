# 洛克王国 PVP 伤害计算器

> 一个用于计算洛克王国 PVP 对战中伤害的工具，帮助玩家更好地制定战斗策略。

## 📖 简介

本项目是一个纯前端网页工具，支持洛克王国中精灵的 PVP 伤害计算。通过输入攻击方和防御方的精灵信息、技能、性格、等级等参数，精确计算出战斗中的伤害值。

**代码来源**：[lovepvp.top](https://lovepvp.top/)
**数据来源**：[BWiki 精灵图鉴](https://wiki.biligame.com/rocom/)

## ✨ 功能特性

- 🎯 **精灵选择**：全部精灵支持名称/拼音搜索，按属性分组浏览
- 📊 **属性计算**：性格修正、个体值、能力等级实时折算六项实战属性
- ⚔️ **三种计算模式**：A 快捷计算 / B 参数配置 / FULL 攻防各 4 技能左右对比
- 🛡️ **特性系统**：攻防特性倍率自动应用，条件类特性支持参数输入
- 🔢 **变动威力技能**：闪击/鸣沙陷阱（速度差/物防差查表）、魔能爆（能量查表）自动换算威力
- ⭐ **收藏夹**：常用攻防配置一键保存、加载（localStorage 持久化）
- 🌙 **深色模式**：日间/夜间主题切换
- 📱 **响应式设计**：适配不同屏幕尺寸

## 🎮 使用方法

1. 打开 `index.html` 文件（可直接在浏览器中打开）
2. 选择**攻击方精灵**：
   - 在搜索框中输入精灵名称（支持拼音）
   - 设置性格、个体值、能力等级等参数
   - 选择使用的技能
3. 选择**防御方精灵**：
   - 同样搜索并选择防御方精灵
   - 设置防御方的性格、个体值等
4. 伤害结果随参数自动实时更新，无需手动点击计算
