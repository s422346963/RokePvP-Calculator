# Update Spirit Skills

该技能用于调整 `spirit_skill.js` 中的精灵技能组数据。

## 使用方法

当用户要求新增技能学习面时调用此技能。

用户需要提供以下信息：

- 要添加的技能名称
- 需要学习该技能的精灵列表（多个精灵用顿号或逗号分隔）

## 示例

- "新增「富养化」学习面:抹茶布丁、伊贝粉粉"
- "在迪莫的技能组中增加火焰踢"

## 功能说明

1. 读取 `data/spirit_skill.js` 文件
2. 根据精灵名称找到对应的精灵技能数组
3. 检查该技能是否已存在，避免重复添加
4. 将新技能添加到技能数组中
5. 保存修改后的文件
